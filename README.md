# Key: Snowthrower (Gemini)

Files from Swami and Izzy's snowthrower key project: a parametric Craftsman snowthrower key modeled in Autodesk Fusion (Fusion 360), first by hand and then regenerated with AI tools (Gemini and Autodesk's Fusion AI).

## What's here

| File | What it is |
|---|---|
| `STKeyV5/` | The Fusion script folder (`STKeyV5.py`, `STKeyV5.manifest`, VS Code `launch.json`). Builds the key with the STKey v5 defaults. |
| `STKEY Autodesk AI generated_.f3d` | The Fusion model generated by Autodesk's AI. Open it in Fusion. |
| `Snow Thrower Key Exported Parameters.csv` | User parameters exported from that model. |
| `final specs used to create the f360 model in md file type.md` | The spec that was fed to Fusion AI to make the model. |
| `snowthrower key for md file.md` | Gemini's recreation of the challenge specs. |
| `Snowthrower key for the phython script.py` | Python script version of the key from Gemini. |
| `f360.f3d file script.py` | The script used to generate the .f3d. |
| `snowthrower Key Challenge.rtf` | The original challenge write-up. |
| `Key(push,showthrower)(Izzy,FB) - FB CHAT.txt` | Messenger chat between Izzy and Swami about the files. |

## How to download

- **Everything at once:** click the green **Code** button near the top of this page, then **Download ZIP**.
- **One file:** click the file, then the **Download raw file** button (the down arrow at the top right of the file view).

## Using the script in Fusion

Copy the `STKeyV5` folder into Fusion's Scripts folder, or in Fusion open **Utilities > Scripts and Add-Ins**, click **+**, and pick the `STKeyV5` folder. Then select it and click **Run**.
